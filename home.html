Help & Guide

What is a High Value Trade Table?

A High Value Trade Table helps you track exchanges in sales deals. It shows what you Give (left side) and what you Get (right side) from customers during negotiations.

Getting Started

  • Create a Table: Enter a name and click "Create Table" to start a new trade table
  • Open a Table: Click "Open" on any table card to view and edit it
  • Check Items: Use checkboxes to mark items you're giving or receiving

Using Your Table

  • Check Items: Check boxes to mark completed trades. Points are automatically assigned (1-20 based on row number)
  • Edit Text: Click on any item text to edit it directly
  • Checkbox Labels: When checking a "Gets" checkbox (right side), a popup lets you add a custom label
  • View Chart: See your "Gives" vs "Gets" totals in the bar chart on the right
  • Status Indicator: Track if your deal is Balanced, Unbalanced, or Poor based on point differences

Editing & Customization

  • Edit Tab: Use the "Edit" tab to modify all items at once, organized by points (1-20)
  • Save Changes: Changes save automatically - no save button needed!
  • Stage Labels: Some rows have stage labels (Discovery, Qualification, etc.) to track deal progress

Sharing & Exporting

  • Share Link: Click "Share" to get a view-only link to share with others
  • Export: Export individual tables or all tables as JSON files
  • Import: Import previously exported tables to restore or share data

Tips

  • Use descriptive names for your tables to easily identify different deals
  • The chart updates in real-time as you check items
  • All data is saved automatically in your browser
  • Checkbox labels you create are saved and will appear when you reopen the table
